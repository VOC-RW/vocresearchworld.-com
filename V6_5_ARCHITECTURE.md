# VOC Research World V6.5 — Researcher & Scientific Identity Architecture

V6.5 extends the V6 content architecture with structured researcher profiles.

## Profile relationships
Researcher → Articles → Research Projects → Publications

## Profile fields
- name, role, affiliation
- discipline
- biography
- research interests and keywords
- contributions
- profile status
- ORCID-ready field (blank until a verified identifier is supplied)

## Current functionality
- searchable researcher directory
- profile pages with metrics
- article/project/publication connections
- research-interest tags
- contribution records
- ORCID-ready architecture

No ORCID identifier is invented. A future backend/CMS can store verified persistent identifiers and additional researcher metadata.
